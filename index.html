How it works

A byte-level workflow without a server round trip

  1. Load bytes. Paste hex, binary, decimal, Base64, or UTF-8 text, or open a file from your device.
  2. Inspect and change. Select offsets to view representations, checksums, hashes, file signatures, and editable bits.
  3. Export deliberately. Save edited bytes or export an offset patch after comparing a reference file.

Privacy by architecture

Your binary data stays in the browser

Bitpeek reads selected files with browser APIs and performs parsing, editing, hashing, string extraction, and comparison in local memory. It does not upload file contents, file names, pasted bytes, or exported patches.

As with any developer tool, keep a backup of important files and validate exported bytes with the software that owns the format.
